# Recurio — Initial Project Setup

## Create Expo App

```bash
npx create-expo-app@latest --template default@sdk-54 ./
```

---

## Start Development Server

```bash
npx expo start
```

---

## Reset Starter Files (Optional)

```bash
npm run reset-project
```

---

## Install NativeWind & Core Dependencies

```bash
npx expo install nativewind@preview react-native-css react-native-reanimated react-native-safe-area-context
```

---

## Install Tailwind CSS Tooling

```bash
npx expo install --dev tailwindcss @tailwindcss/postcss postcss
```

---

## Generate Metro Configuration

```bash
npx expo customize metro.config.js
```

---

## Install Additional Utilities

### clsx (Conditional Class Names)

```bash
npm i clsx
```

### React Native Safe Area Context

> Usually installed with NativeWind dependencies above, but can be installed separately if needed.

```bash
npm i react-native-safe-area-context
```

---

## Run Application

### iOS Simulator

```bash
npx expo start
```

Then press:

```bash
i
```

---

### Android Emulator

```bash
npx expo start
```

Then press:

```bash
a
```

---

### Expo Go (Physical Device)

```bash
npx expo start
```

Scan the QR code using:

* **Expo Go** (Android)
* **Camera App** (iPhone)

---

## Production Build (Later)

### Install EAS CLI

```bash
npm install -g eas-cli
```

### Login

```bash
eas login
```

### Configure EAS

```bash
eas build:configure
```

### Android Build

```bash
eas build --platform android
```

### iOS Build

```bash
eas build --platform ios
```
